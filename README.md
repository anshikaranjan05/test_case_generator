# Automated Test Case Generator using AI

## 👩‍💻 Team Members
- Anushka Dutta - 500121771  
- Anshika Ranjan – 500120441  
- Himangi Tyagi – 500118972  

## 📌 Project Overview

This project is a tool that uses AI to automatically generate test cases from source code or software requirements. The goal is to reduce manual effort, improve code coverage, and increase the reliability of software testing.

## 🚀 Features

- Accepts input source code or specifications (`.py`, `.java`, `.txt`, `.md`, `.docx`)
- Parses code and analyzes logic and control flow
- Uses AI to infer unit, integration, or functional test cases
- Exports test cases in multiple formats: `.json`, `.xml`, `.csv`, and testing frameworks like JUnit or PyTest
- Provides a user interface for viewing, editing, and exporting test cases
- Supports optional integration with tools like GitHub and Jenkins

## ⚙️ Technologies Used

- Python, Java (initially supported languages)
- Machine Learning / NLP models for parsing and inference
- Web technologies (for UI, if web-based)
- REST APIs (for integration)

## 🔒 Security and Performance

- Sandboxed code submission
- Secure access (HTTPS)
- Fast response for inputs < 500 lines of code
- Concurrent user support (cloud deployment)
- Privacy-safe — no permanent storage unless allowed

## ✅ Functional Requirements

- Accept code/spec file inputs
- Analyze logic and control flow
- Generate and export test cases
- UI for user interaction
- Configurable test depth, coverage, etc.

## ❗ Non-Functional Requirements

- < 5 sec response time for inputs < 500 LOC
- Browser compatibility (if web)
- 80%+ AI accuracy for logic detection

## 📂 Folder Structure (Example)

```
/project-root
├── sample_code.py
├── test_generator.py
├── test_generated.py
├── README.md
```

## 🛠️ How to Run (Python Prototype)

1. Place your Python code in `sample_code.py`.
2. Run the generator script:
   ```bash
   python test_generator.py
   ```
3. Check `test_generated.py` for auto-generated test cases.

## 🧠 Future Scope

- Add more language support (e.g., C++, JavaScript)
- Parse natural language requirement documents
- Advanced model training for better accuracy
- Full web-based interface with drag-and-drop support
